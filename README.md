# Employee-Engagement-Retention-Analysis
Description: Analyzed employee data (attrition, performance, department-wise metrics, hiring trends). 
Developed key HR KPIs and built an interactive dashboard to monitor workforce insights. The dashboard 
facilitated data-driven HR decisions and strategic planning. 
❖ Skills Demonstrated: 
•  Data Cleaning & Transformation 
•  Exploratory Data Analysis (EDA) 
•  Data Visualization 
•  KPI Development & Dashboard Creation 
❖ Tools Used: Tableau, Power BI, Advanced Excel, SQL. 
❖ Insights Gained & Business Impact: 
•  Uncovered key attrition trends, enabling HR to proactively reduce employee turnover. 
•  Identified high-performing departments to optimize hiring and retention strategies. 
•  Provided dashboard-driven insights that improved resource planning and overall workforce efficiency.
